# Apex Tech E-Commerce Web Application

A full-stack e-commerce platform built as part of the Software Engineering 371 project at Belgium Campus iTversity. The application provides a complete online shopping experience for high-end PC hardware and gaming peripherals, featuring user authentication, dynamic product filtering, a slide-over cart drawer, secure checkout workflows, and automated CI/CD testing.

---

## 🚀 Tech Stack

* **Frontend:** React.js, Vite, Tailwind CSS
* **Backend:** Node.js, Express.js (MVC & Repository Pattern)
* **Database:** MySQL managed via Sequelize ORM
* **Testing & DevOps:** Vitest, Postman API Collections, GitHub Actions CI/CD
